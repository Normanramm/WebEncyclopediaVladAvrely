> **Полный справочник по HTML5, CSS3 и JavaScript** с живыми примерами и визуальным отображением каждого тега и свойства. Создан в стиле Apple — минималистично, элегантно, понятно.

## ✨ Возможности

- ✅ **HTML теги** с полным описанием и атрибутами
- ✅ **CSS свойства** с интерактивными примерами
- ✅ **JavaScript конструкции** с живым выводом
- ✅ **Python** синтаксис и примеры
- ✅ **Тёмная тема** (автоматически подстраивается под систему)
- ✅ **Поиск** мгновенный поиск по всем тегам и свойствам
- ✅ **Копирование кода** копирование примеров одним кликом
- ✅ **Адаптивный дизайн** для всех устройств
- ✅ **Визуальные preview** каждый пример кода сопровождается результатом
- ✅ **Apple-style** дизайн минималистичный и элегантный интерфейс
- ✅ **Быстрая навигация** переключение между разделами без перезагрузки

## 🚀 Быстрый старт

# Клонируй репозиторий
