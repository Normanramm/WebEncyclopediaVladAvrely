🎯 О проекте
Web Encyclopedia Vlad Avrely — это интерактивный справочник для веб-разработчиков, созданный в современном стиле Apple. Содержит полную документацию по HTML5, CSS3 и JavaScript с живыми примерами кода и визуальными превью.

✨ Особенности
🎨 Apple-style дизайн — минималистичный и элегантный интерфейс
🌓 Тёмная тема — автоматическое переключение через prefers-color-scheme
🔍 Живой поиск — мгновенный поиск по всем тегам и свойствам
📱 Адаптивность — полная поддержка мобильных устройств
📋 Копирование кода — копирование примеров в буфер
🎯 Визуальные превью — каждый пример кода сопровождается результатом
⚡ Быстрая навигация — переключение между разделами без перезагрузки
